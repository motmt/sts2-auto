# StealthKit · 杀戮尖塔2 联机潜行助手

两档用法：
- **单人安装**：`stealth give …`（定向送卡/遗物/药水/金币/休息回复）——只需你自己装，走官方商店同步通道，不不同步。
- **全员安装（v0.4 注入愿望）**：`stealth wishcard 卡名` —— 把**下一层卡牌奖励的第三张直接换成你选的卡**，
  全队画面、历史记录天然一致（提前把随机变成必然）。需要**全体联机者都启用同版本 StealthKit**。

> 适配版本：游戏 **v0.111.0**。大版本更新后如失效请重新编译。

---

## 原理（30 秒版）

- 商店买卖用的 `RewardObtainedMessage`（主机自动中继给全体）携带完整卡牌数据，任意一端发出后每台机器各自执行**原生**加牌逻辑 → 送卡/遗物/金币只需自己装，绝不不同步。
- 卡牌三选一由全队用同一随机种子在每台机器上生成。若**全队都运行同一段“替换第三张”的代码**（StealthKit v0.4），
  替换结果在每个端一致 → 选卡按序号依旧同步，队友看到的奖励和你完全一样，历史也自然。

## 功能与用法（游戏内按 `~` 打开控制台输入）

**不用记 ID！** 支持 **中文名或名字片段** 搜索，命中唯一直接执行，命中多个列编号后用 `stealth take <编号>`：

| 指令 | 效果 |
|---|---|
| `stealth wishcard 献祭` | **（需全队装 v0.4）** 把下一层 3 选 1 的第三张换成这张卡；想一直必出就保持别取消 |
| `stealth wishcard off` | 恢复随机 |
| `stealth give card 死亡收割` | （仅需自己装）按中文名搜卡并悄悄加入牌组 |
| `stealth give relic 血` | 按名称搜遗物并悄悄获得 |
| `stealth give potion 火` | 按名称搜药水并悄悄获得 |
| `stealth give gold 999` | 直接加/扣金币（正数加） |
| `stealth find card 格挡` | 只搜索列编号 |
| `stealth rest` | 休息点立刻执行一次回复 |
| `stealth autoheal on/off` | 进休息点自动回复一次 |
| `stealth status` / `stealth help` | 状态 / 帮助 |
| `sk 3 <卡名>` | **自动自然落地**：等下次进商店(按价购买记录)或事件(事件获得记录)时悄悄拿卡，队友 hover 该层与真实形态一致、无三选一破绽（单人即可） |
| `sk 6 <增益> <层数>` | **本关增益（单关卡有效）**：设置后当前这场战斗**立即生效**（战斗中设置也会立即补上；同种增益按增量叠加）；**该场战斗结束即自动清空**，不带到下一关。`sk 6 力量 4`、`sk 6 敏捷 2`、`sk 6 <英文ID> <层数>` 均可；`sk 6 off` 清空、`sk 6` 查看。力量/敏捷图标战斗中队友可见，属明面增强 |


> 提示：若用 `give` 直接送卡后，在同一层随后的 3 选 1 里选择“全跳过”，本机会把该层历史改写成
> “获得了这张卡 + 跳过 2 张”以自洽（仅改写本机记录；队友机器各自的记录无法被本工具修改）。
> 使用 v0.4 的 `stealth wishcard` 注入模式则完全不需要这些补丁——奖励第三张真的就是你选的卡，
> 队友画面与历史天然一致。

## 安装

1. 关闭游戏。
2. 把 `StealthKit` 文件夹放进 `E:\steam\steamapps\common\Slay the Spire 2\mods\`
   （最终：`...\mods\StealthKit\StealthKit.dll` + `StealthKit.json`）。
3. 启动游戏 → 主菜单 **Mod** → 启用 **StealthKit** → 重启游戏。
4. 联机进局，在非战斗时刻按 `~` 输入 `stealth help` 即可使用。

> **v0.4 注入愿望（奖励必含某张卡）要求：全体联机者都启用相同版本的 StealthKit。**
> 若有人没装/版本不一致，只有你这边换了牌，会导致按序号同步时选到不同的卡 → 数据不同步，请务必全员一致。

> 队友提示：本 mod `affects_gameplay=false`（不改变游戏数据库），联机不会因此被判定版本不一致，
> 队友端以原版逻辑处理你发出的数据。若队友是“完全没开过 mod 的原版模式”，游戏可能提示
> “主机装了额外 mod”，一般可正常继续；最稳妥是让队友随便开一个小 mod（或开启 full_console）进入 modded 模式。

## 重要限制（为什么有些“理想方案”做不到）

1. **奖励面板替换的两种形态**：
   - 单人安装（队友不装）：无法改变面板，只能走 give 送卡通道（历史需靠 v0.3 本机美化兜底）。
   - 全员安装 v0.4：可以用 `stealth wishcard` **真的把下一层 3 选 1 的第三张换成你选的卡**（全队一致）。
2. **give 类指令必须在“非战斗”时刻使用**：官方商店通道在战斗中禁止发送（这是它保证一致性的设计）。
3. **只能发“原版”或“队友也装了”的内容**：消息里要带完整卡牌数据，队友端必须有该内容才能解析。
4. 精密改血（如“回 45%”/“回满”）没有对应的官方同步消息，只能借“休息点回复(30%基础)+遗物加成”这类
   官方流程近似；若要任意数值回复且队友也允许装 mod，可配合 ConsoleSyncGuard 的房主控制台(`heal`)使用。
5. 联机时**不要**开风灵月影等外部修改器——它绕过游戏网络层直接改内存，任何 mod 都救不了。

## 源码与编译

```
cd StealthKit
dotnet build -c Release -p:Sts2DataDir="<游戏目录>\data_sts2_windows_x86_64"
```
把 `bin/Release/StealthKit.dll` 与 `StealthKit.json` 放入 `mods/StealthKit\`。
源码：`src/ModEntry.cs`（入口）`src/Core.cs`（潜行通道核心）`src/StealthCmd.cs`（控制台命令）`src/Patches.cs`（火堆自动休息触发）。

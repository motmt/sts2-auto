# 问心无愧 · ClearConscience（杀戮尖塔2 模组）

> 适配游戏 **v0.111.0**。灵感来自塔一创意工坊 mod《问心无愧 Mod》（作者 wsblby），
> 交互方式也照它做：**战败时结算屏出现「问心无愧」按钮，点了才保档**。

---

## 它做了什么

塔一那版：死亡画面多一个「问心无愧」按钮，点了 → 回主菜单不删存档 → 还能「继续游戏」。
杀戮尖塔2 的删档发生在「一局结束」流程中，所以我们把那次删除**先暂缓**，交给按钮决定：

| 你在战败结算屏的操作 | 结果 |
|---|---|
| 点「**问心无愧**」 | **保留 run 存档** → 单机回主菜单点「**继续**」、联机回多人菜单点「**读取**」 → 回到最近的存档点（通常本层开始）重打 |
| 不点，直接点「返回主菜单」 | 正常清档（和原来一样） |
| 胜利 / 主动「放弃」 | 正常清档 |

**默认开启**；控制台 `cc off` 关闭、`cc on` 打开、`cc` 看状态。
按钮出现在结算屏「返回主菜单」附近（复制的是游戏原生按钮，样式/字体与游戏一致）。

## 联机怎么用（重点）

- **只有房主需要安装**：联机 run 的存档只保存在房主端（原版只对 房主/单机 执行删除）。
- 房主战败 → 结算屏点「问心无愧」 → 存档保留 → 房主在**多人菜单点「读取」**续开这局，队友重新进来 → **全队一起回到那一层**。
  所有人始终以房主的 run 状态为准，**不会数据不同步**。
- 客机装了不冲突，但没有本地 run 档可保（所以没用）。

## 安装

1. 关闭游戏。
2. 把 `ClearConscience` 文件夹放进 `E:\steam\steamapps\common\Slay the Spire 2\mods\`
   （最终：`...\mods\ClearConscience\ClearConscience.dll` + `ClearConscience.json`）。
3. 启动游戏 → 主菜单 **Mod** → 启用 **问心无愧** → 重启游戏。

## 控制台命令

| 命令 | 作用 |
|---|---|
| `cc` | 查看状态与用法 |
| `cc off` | 关闭（战败正常清档） |
| `cc on` | 打开（默认） |

配置存在 `mods/ClearConscience/ClearConscience_config.json`（`enabled`）。

## 原理（30 秒）

- 每局结束都会走 `RunManager.OnEnded(isVictory)`；主动放弃会先设 `IsAbandoned = true`。
- 结束流程中会调用 `RunSaveManager.DeleteCurrentRun()`（单机）或 `DeleteCurrentMultiplayerRun()`（房主），
  删除 `current_run.save` 与 `.backup`，于是「继续/读取」入口消失。
- 本模组：**战败时把这次删除拦下（暂缓）**，并在结算屏注入「问心无愧」按钮；
  - 点了 → 保留存档；没点、返回主菜单 → 这时才真正执行那次删除。
- 不改动游戏内任何状态与随机数，所以不影响联机校验。

## 已知边界

- 只能回到**最近的存档点**（存档在进入房间/事件等节点时写入），通常就是这一层战斗开始前。
- 如果战败后**直接关掉游戏**（没点按钮也没返回主菜单），存档会保留到下次启动 —— 相当于默认保档；介意的话回来点一次「返回主菜单」即可清掉。
- 按钮位置/样式若与你期望不同，告诉我可调。
- 跨版本更新后如失效请等我重编。
